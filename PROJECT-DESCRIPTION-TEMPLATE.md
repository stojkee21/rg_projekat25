# The Lantern House

301/2020 - Nemanja Stojadinović

The scene represents an **old wooden house** standing on a **stone floor**, surrounded by a subtle atmospheric
environment.  
A **street lamp** model adds realism to the composition, with dynamic lighting effects that illuminate the area.  
The scene features interactive lighting controls, smooth camera movement, and real-time shading that brings the rustic
environment to life.

## Controls

**L** → Toggles the point light on and off.  
**C** → Activates a chained light action sequence — the lamp turns red, then blue, and finally turns off automatically
after
a few seconds.  
**F** → Shows or hides the graphical user interface (GUI).  
**W**/**A**/**S**/**D** → Moves the camera around the scene, allowing free exploration of the environment.

## Features
